# Sales ABC & Warehouse Analysis Dashboard

## Описание проекта

Power BI-проект для анализа продаж, товарного ассортимента и показателей складов.

## Инструменты

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- ABC Analysis

## Задачи проекта

- Анализ продаж
- ABC-сегментация товаров
- Анализ товарных остатков
- Сравнение показателей по складам
- Анализ выручки и прибыльности
- Выявление наиболее значимых товарных позиций
- Расчет ключевых KPI
- Создание интерактивных фильтров и визуализаций

## Использованные инструменты

- Power Query
- DAX
- Relationships
- KPI
- Filters
- Charts
- ABC Analysis
- Interactive Dashboard

## Результат

Дашборд помогает оценивать продажи, структуру товарного ассортимента и эффективность складов, а также выявлять наиболее значимые товары по результатам ABC-анализа.
